PROJETO DASHBOARD - GITHUB PAGES

Os links das 4 bases já foram inseridos no arquivo app.js:

- MOP
- Relatório de satisfação
- Blip
- Agent

COMO USAR:

1. Extraia este ZIP.
2. Suba os arquivos no seu repositório GitHub:
   - index.html
   - style.css
   - app.js
   - README.txt

3. No GitHub, vá em:
   Settings > Pages

4. Em Source, escolha:
   Deploy from branch

5. Escolha:
   Branch: main
   Folder: /root

6. Clique em Save.

7. Aguarde o GitHub gerar o link:
   https://seuusuario.github.io/nome-do-repositorio/

8. Use esse link no Power BI.

IMPORTANTE:
Como suas bases estão publicadas como CSV no Google Sheets, qualquer pessoa com o link pode acessar os dados.
Não use esta opção para dados sensíveis sem camada de autenticação.
